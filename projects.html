1. Database Design and Development

I designed and created a Microsoft SQL Server database to store and manage the data used by my PC website. This database serves as the foundation of the project.

Tables and Views

I created tables and views to organize and retrieve data, while working to reduce unnecessary duplication and maintain data consistency.

Database Relationships

I used SQL Server Management Studio's Database Diagram tool to visualize the relationships between tables and review the overall database structure.

Users and Permissions

I configured database users and permissions to control access. The API handles database communication instead of exposing database credentials in the frontend.

Technologies Used

Microsoft SQL Server · SQL Server Management Studio · SQL

2. API Development

I developed an ASP.NET Core API to connect the website to the database. It retrieves product data and allows new products to be saved.

The API uses Entity Framework Core to access the database and provides endpoints for retrieving individual products, listing products and creating new products.

3. Website Integration

Product Page

I connected the website to the API so products are loaded from the database. I also implemented product search, model filtering, minimum and maximum price filters, and a clear-filter button.

Adding Products

I added a form that allows new products to be submitted through the website and saved to the database through the API.

Technologies Used

HTML · CSS · ASP.NET Core · Entity Framework Core · SQL Server

Digipet

Digipet is a C# console game where players care for a virtual cat or dog, improve their stats, fight monsters and progress through the game.

Features

  • Pet care through feeding, training, playing and sleeping.
  • Pet stats including health, hunger, happiness and attack power.
  • Turn-based combat against monsters to earn gold and level up.
  • A weapon shop with different weapons and level requirements.
  • Save and load pet stats using text files.
  • Randomised events and stat changes.

Technologies

C# · Object-Oriented Programming · Interfaces · File Handling

What I Learned

Working with classes, interfaces, properties, methods, random number generation, timers and file handling.
